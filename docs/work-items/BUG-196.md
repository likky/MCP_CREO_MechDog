# BUG-196 Creo 11 实测修复未回流主干

分类：**已有修复但待验收**。稳定性/查询契约，P1，目标版本未排期（随本次整合提交）。
（本卡原为本地 `BUG-194`；上游 0.47.0 已把 `BUG-194` 用于 `auto` 求解器路由修复，故重编号为 `BUG-196`。）

来源为本地 0.19.3 分支提交 `1d6a4cb`（2026-11-12）与
[Creo 11 实测报告](../archive/creo11-2026-11/CREO11_TEST_REPORT.md) 3.3/3.5 两节。
该提交基于 `2c78aaa`（v0.19.3），入口重构为 `src/creo_mechdog/` 包、根 `bridge.py` 只剩转发，
因此原始补丁不能直接合入；先在 v0.46.1 上重放，再随 v0.47.0 主干重放一次。

## 现象

1. MCP 宿主只给最简环境时，异步 Toolkit 连接返回 `-4`（`PRO_TK_E_NOT_FOUND`），启动探测永远不就绪；
   根因是 `windows_process_environment()` 回填白名单缺少 `PTCNMSPORT`。
2. Creo 11 上普通特征作业的 `creo_get_job` 完整视图约 35 KB，超过 `RESPONSE_BUDGET`（32 KiB）后被
   推进分页视图，而分页视图没有顶层 `result` 块，读内联结构的客户端直接 `KeyError: 'result'`。

## 范围

- `windows_process_environment()` 白名单补 `PTCNMSPORT`、`PRO_DIRECTORY`。
  `PTC_D_LICENSE_FILE` 不加入：当前实现由 `resolve_license_environment()`（含 `parametric.psf` 兜底）
  统一授予，`tests/test_creo_startup.py` 有“不得从用户环境块导入”的既有用例。
- 新增 `job_pages.INLINE_WHOLE_BUDGET = 64 KiB`：只放宽“整份内联”门槛；`RESPONSE_BUDGET`(32 KiB)
  与分页单页上限保持不变。
- 明确不采纳原补丁的两项：探测超时 `2 -> 10` 秒已被可配置的 `creo_probe_timeout_seconds`
  （默认 15）取代；`CURSOR_RESERVE = 512` 已被 FEAT-023 的裁剪循环取代。

## 验收

- 离线：合成作业在 32.1 KB / 35.3 KB / 38.5 KB 三档都保持内联且带顶层 `result`；超过 64 KiB 仍分页。
- 单测：`tests/unit/test_job_query_protocol.py`、`test_large_plan_result_budget.py`、
  `test_job_projection.py` 与 `tests/test_creo_startup.py` 全通过。
- 实机：Creo 11 复跑连接与 35 KB 作业读取。本轮未执行（未连接 Toolkit、未启动 Creo）。

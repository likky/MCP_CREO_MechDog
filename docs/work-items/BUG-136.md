# BUG-136：mate_offset/align 被错误要求提供圆柱面，顶层文案与实际约束类型不符

分类：**部分交付 0.33.0**（本机 Creo 10 六类约束实机通过、平面/圆柱面按类型要求；Creo 12.4 与 Arm7 原模型未验）。

类型：缺陷

优先级：P2

状态：待验收（2026-11-20 本机 Creo 10 实机通过全部分类；Creo 12.4 与 Arm7 原模型未验）

目标版本：0.33.0（候选）

来源与关联：0.31.1 反馈“Arm7 / 装配 0.31.1 复测”（60 条配合中 mate_offset 报错）；关联 [BUG-132](BUG-132.md)。

分类依据：待验收——离线实现与单测完成，本机 Creo 10 实机覆盖平面成功、圆柱拒绝、insert 圆柱要求、csys 放行；Creo 12.4 与 Arm7 原模型仍缺。

## 问题或目标

装配约束准入检查 `require_constraint_surface_type` 把所有非 plane 类型都当作圆柱要求：`mate_offset`、`align`、`align_offset` 实际需要平面，却被要求提供圆柱面。同时顶层错误文案没有写实际约束类型，用户按提示修改也无法改对。

## 范围

1. `native/advanced.cpp` 给 `require_constraint_surface_type` 增加 `constraint_type` 参数。
2. 分类：`plane_required` 为 `mate` / `mate_offset` / `align` / `align_offset`；`cylinder_required` 为 `insert`；`csys` 跳过该检查。
3. 文案输出实际约束类型（例如 `mate_offset needs a real plane`）。
4. 不包含：不改变约束求解逻辑，不放宽 `mate`/`coincident` 的平面要求，也不改动 insert 的圆柱要求。

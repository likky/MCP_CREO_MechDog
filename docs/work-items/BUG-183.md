## 修复内容

1. **原生求解截面面积**：`native/generic.cpp` 的 `section_profile_summary` 使用 `ProSectionEntityEval` 采样已求解 `ProSection` 中的直线、圆弧、样条、B 样条、圆、椭圆与多段线，追踪闭合环与内外嵌套并计算 `solved_section_area_mm2`，随草图 `native_section`、零去料 `cut_geometry_context` 及成功拉伸切除回执一并发布。
2. **闭合 B 样条草图除料风险提示**：`src/creo_mechdog/operation_results.py` 在含 `b_spline_entities > 0` 且 `closed_contours > 0` 的草图回执中补充 advisory `b_spline_cut_risk`，提示 Creo 闭合 B 样条除料可能出现零去料或静默少切，并建议使用 `cut_volume_check`/`solved_section_area_mm2` 核验或改用 `approximation_segments`。
3. **`cut_volume_check` 扩展**：支持 `blind` 与 `symmetric` 两种有限深度切除，当 `profile.material_area_mm2` 为 `null`（如 B 样条）时自动回落至 `solved_section_area_mm2`（标注 `area_source="native_solved_section"`），并在含 B 样条时附 `b_spline_entities` 与 `b_spline_cut_risk=true`；同步更新 `cut_geometry_context.py` 与 `compact_sections.py`。

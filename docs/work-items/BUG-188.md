# BUG-188 coordinates 模式拒绝构造实体

分类：**待实现**。缺陷，P0，目标版本未排期。

来源为 [0.43.1 反馈](../validation/feedback-0.43.1-2026-11-24/originals/datum-plane-normal-sketch-axis-flip.md) §2。`dimensioning="coordinates"` 遇到构造圆即报 `Coordinate dimensioning accepts lines, polylines, rectangles, circles, arcs and exact B-splines only`，真实草图里的构造圆和构造线只能整批删除，草图与源件不再同构。

原生坐标尺寸只识别 `PRO_2D_LINE`、`PRO_2D_CENTER_LINE`、`PRO_2D_CIRCLE`、`PRO_2D_ARC` 与 `PRO_2D_B_SPLINE`；参考 SDK 的 `Pro2dEntdef.h` 另有 `PRO_2D_CONSTR_CIRCLE = 10`。

## 范围

- 原生坐标尺寸识别 `PRO_2D_CONSTR_CIRCLE`，按圆记录并把实体标记为构造；构造实体进入快照、声明 `construction=true`，仍按普通圆建立坐标尺寸以保持求解稳定。
- 构造线的实际类型与构造标记同样放行；几何校验与剖面快照按圆处理，不再误判为线。
- Python `SketchOp` 的 coordinates 允许集与原生能力保持一致。

## 验收

含 2 个构造圆与 3 条构造线的草图在 `dimensioning="coordinates"` 下成功；非构造轮廓仍有坐标尺寸；`geometry_deviation` 不因构造实体改变；Creo 10 实机保存重载通过。失败路径回滚且 revision 不变。

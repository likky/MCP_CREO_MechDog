# BUG-158：披露作业预算与停滞预算

分类：**开发中**。优先级 P0（0.35.5 反馈 P0 批次）。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §十一。现场无法判断 `timeout_seconds` 是否同时抬高停滞看门狗预算，只能靠杀作业试探。

范围：提交 manifest 与 `creo_get_job` 运行态同时给出 `job_timeout_seconds`、`timeout_source`、`stall_watchdog_seconds`、`stall_watchdog_source`，并列出观察文件 `worker.log`、`native.log`；compact 回执保留同一组字段。预算语义不变：停滞预算独立于作业预算，作业预算仍是最终上限。

验收：提交回执、运行中、终态三种投影的预算值一致；单元测试覆盖。未验：真实客户端长作业试探、Creo 9/12。

# BUG-168：live.loaded 与会话清单矛盾、open_file 冲突与只读导出版本

分类：**待规划**。优先级 P1。来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §十八（18.3–18.6）。

现象：`creo_list_session_models` 显示模型在会话中，`creo_reconcile_model` 的 `live.loaded=false`，`creo_open_file` 又返回“当前会话已有冲突”，三件工具互相矛盾；`unknown_outcome` 零件/装配因此无法继续。另发现只读导出会占用模型并阻止写作业。需要统一会话真相源（会话存在 vs 当前模型 vs 已加载），定义 `creo_open_file` 冲突的确定性出口，并让只读导出不创建 revision、不长期占用写锁；`abandon_new` 不应只依赖 origin 所有权。验收：三工具对同一模型给出一致判定；只读导出后写作业可继续；unknown_outcome 有可用恢复路径。未验：报告原始会话与 Creo 9/12。

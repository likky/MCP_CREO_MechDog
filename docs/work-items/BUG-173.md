# BUG-173：斜置三点基准面草图自动补齐垂直锚定参考与解算错误精准归因

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.40.0 已交付并完成本机 Creo 10.0.0.0 实机验收；外部原始 `frigate_v4` 模型、Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.40.0（MINOR）

来源：[0.35.8 原始反馈（三点基准面草图）](../validation/feedback-0.35.8-2026-11-23-hang-recovery/originals/three-point-plane-sketch-reference-and-autodim-misreport.md) §1–§7，以及 [0.35.8 原始反馈（验证挂起与恢复硬限）](../validation/feedback-0.35.8-2026-11-23-hang-recovery/originals/verify-hang-and-recovery-90s-deadlock.md) §3。

## 修复内容

1. `native/generic.cpp`：
   - 在 `sketch()` 创建未完成草图特征前，检查模型是否已存在同时垂直于支撑面（`|dot(n, frame.n)| < 1e-5`）与 orientation 面（`|dot(n, orient_normal)| < 1e-5`）的基准面；主平面 XY/XZ/YZ 天然满足（零额外特征），而在单轴倾斜的三点基准面（如 B045/B047/B104/B105，`orientation_exact=true` 但缺第二个正交基准面）上，自动调用 `build_helper_anchor_plane()` 创建一个过草图轮廓形心、法向为 `normalized(cross(frame.n, orient_normal))` 的辅助基准面（日志 `SKETCH_ANCHOR_HELPER=1`）；同一斜基准面上的后续草图自动命中并复用该辅助面；
   - 候选基准面投影按正交等级分层（`tier0` 双正交面 → `tier1` 垂直于支撑面 → `tier2` 其余非平行面），首条正交面即投影成功并提前终止，不再对数百个斜基准面重复触发 `PRO_TK_BAD_INPUTS (-2)`；
   - 草图回执与 compact 投影新增 `section_references`（`anchor_count`、`reference_incomplete`、`helper_orientation_created`、`helper_anchor_created`、`entity_count`、`origin_pin_u`、`origin_pin_v`、`origin_pin_available`）。
2. `native/sketch_coordinates.cpp` 与 `native/sketch_solver.cpp`：
   - `pin_coordinate_origin()` 将 `u`/`v` 轴原点固定状态写入 `last_sketch_reference_info`；
   - `coordinates` 模式下 `ProSectionSolve` 失败且救援 `ProSectionAutodim` 也失败时，先将 `solver` 与 `section_references` 写入 `staged_operation_result`，再抛出包含 `ProSectionSolve` 失败码、`retry_without_inference` 码、救援 `ProSectionAutodim` 码及 `[anchors=..., reference_incomplete=..., origin_pin_available=..., entities=...]` 的明确错误，不再误报为单纯 `AutodimensionSketch` 失败。

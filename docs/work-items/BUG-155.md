# BUG-155：边选择器匹配后按曲面类型解析

分类：**开发中**。优先级 P0（0.35.5 反馈 P0 批次）。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §二（现象 §2.1，对照 §2.2）。现场环境 Windows 10 19045 / Creo 10（release_numeric 41）/ v0.35.5。

反馈事实：`geometry_selector(target=edge)` 在 P03 垫板上匹配成功后，`ProModelitemInit(board, id, PRO_EDGE)` 返回 `-23`（作业 `402bc915…`）。同一组边改用显式 id 67–74 成功（作业 `d5ab8ee…`），说明 id 有效，失败发生在“选择器结果转 `ProSelection`”这一段。

根因：`native/geometry_selectors.cpp` 的边匹配器成功分支没有写 `GeometrySelectorOutcome::target`；`native/generic.cpp` 的 `resolve()` 以 `target == "edge" ? PRO_EDGE : PRO_SURFACE` 选择类型，空值被当成曲面，边 id 按 `PRO_SURFACE` 初始化即 `-23`。曲面匹配器在入口写了 `"surface"`，边匹配器漏写。

范围：修正 `target` 赋值；`resolve()` 在匹配后用 `ProEdgeInit`/`ProSurfaceInit` 校验类型并在失败时给出 target、id、候选数与匹配诊断。不采用“失败后改试另一类型”的兜底。

验收：`tools/test_feedback0355_selector_round.py` 用端点选择器对同一组边圆角成功；显式 id、曲面选择器回归通过；保存重载 `saved_file_reloaded_and_verified=true`。未验：Creo 9/12、外部 WorkBuddy 黑盒、报告原始模型。

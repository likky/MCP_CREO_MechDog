# BUG-186 验证钣金法兰伸展方向和厚度侧

分类：**已有修复但待验收**。缺陷，P1，目标版本未排期。

来源为 [0.43.0 机械臂反馈](../validation/feedback-0.43.0-2026-11-24-arm/originals/arm-sheetmetal-stl-and-edge-selectors.md) §1.1–1.2。报告的 90° 法兰切换 `flip` 时横腿沿 Y 反向，Z 范围一直为 [0,12]。Arm2 所需真实钣金本体的包络为 X [-10,10]、Y [-2,8]、Z [-2,12]。

先用 Creo 10.0.0.0 和匹配 SDK 重建 20×12×2 mm 竖腿与 R0.7366 内弯，控制同一条挂接边。SDK 对 `PRO_E_SMT_FLANGE_SEC_FLIP` 和 `PRO_E_SMT_WALL_THICKNESS_FLIP` 分别标记为 Flip Section Side 和 Flip Thickness。当前代码将后者固定 false，是否能做出所需材料位置取决于单变量实测。

验收要求四种伸展与厚度侧组合的实际几何和状态、旧参数兼容、独立体积依据与保存重载。失败路径检查 revision 和回滚证据；缺参照或暂不支持的组合保留限制。


## 本机 Creo 10 实测和修复

`flip` 继续控制截面伸展，新增 `flip_thickness` 通过 `PRO_E_SMT_WALL_THICKNESS_FLIP` 控制自由端一侧的板厚。两者均相对挂接面，缺省保留旧几何。新增字段由计划与独立工具共同接受。

| flip | flip_thickness | 实测 Y 范围 mm | 实测 Z 范围 mm | 体积 mm³ | 作业 |
| --- | --- | --- | --- | ---: | --- |
| false | false | -2～8 | 0～12 | 770.185801 | `f98a1948eb564bbfbf617518a2a768c7` |
| false | true | -2～8 | -2～12 | 850.185803 | `2e20756dad9b449e9e8f37e391a17381` |
| true | false | -10～0 | 0～12 | 770.185802 | `9e1fbeec9e8746b381f8583c6a359d03` |
| true | true | -10～0 | -2～12 | 850.185803 | `a94ad1e9f18c47edb23cca87fbe8d22f` |

四件均通过原生保存重载，X 方向范围均为 [-10,10]。外伸厚度使毛坯增加 `20 × 2 × 2 = 80 mm³`，实测吻合。目标双圆柱半径 0.7366/2.7366 mm，YZ 圆心为 (0.7366,0.7366)。旧参照作业 `705fea73aedb4999879062e8c6b47fb5`、`60a24bc4021d48279f5cc5b735653caf` 与关闭新开关的结果一致。

环境为 Windows x64 / Python 3.12.10 / Creo 10.0.0.0（release numeric 42）和匹配 SDK。从 `1e2cea90d3337a6401760bf50b7b07a05944f7f5` 开发，dirty=true。四组合原型受测源码指纹 `a1b237290602b82e75a8eaaf1e8f4f8b98a678701f46aa76044c4fbf727bec05`。运行 `python bridge.py build`、`python build/bug186/probe.py baseline` 和 `python build/bug186/probe.py thickness`，通过开发桥接在临时新模型上验证。报告保存在本机 `build/bug186`，四组合报告 `thickness.json` 的 SHA256 为 `8a60d6a82e18db34d6c805a64ed1d3abb4f10b5ccf369bb53acf642a1f6f4d78`。

本体组合法兰、反例回滚和同一毛坯的 STL 另见 [FEAT-084](FEAT-084.md)。其它角度、沿曲边的厚度位置、Creo 9/12、原报告方完整零件后的外部复测待验。

## 2026-11-24 新反馈补充

0.43.2 报告 §2.2：`sheetmetal_base_flange` 只能新建独立两段链，第二腿固定朝板法向反侧，无法得到向 +Z 的止口。仓库已有 `SheetmetalFlangeOp` 可挂到已有壁自由端，需先用当前工具实测复核，再判断是否仍缺 `attach_to`/第二腿方向控制；见 [FEAT-089](FEAT-089.md)。来源见 [DEV-101](DEV-101.md)。

# BUG-180：`round`/`chamfer` 单/多边失败几何层诊断与 `round` 凹凸/加去料回执

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.42.0 已交付并完成本机 Creo 10.0.0.0 实机验收；Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.42.0（MINOR）

来源：[0.40.0 原始反馈（护卫舰 chamfer 切向链延伸与 round 失败无诊断）](../validation/feedback-0.40.0-2026-11-24/originals/frigate-chamfer-tangent-chain-and-round-diagnostics.md) §2、§6 P5、§8 问题 2。

## 修复内容

1. **单边与多边失败几何层诊断**：`native/generic.cpp` 在 `generic_round` 失败时（单边与多边均触发）采集 `ProFeatureStatusGet` 状态码/名称及 `diagnose_round_edges`（边长、两侧相邻面 ID/类型/面积/中点法向、中点二面角、两端点邻边数量、最短邻边长度与相切邻边 ID），写入 `round_failure.edge_diagnostics` 并在 compact 失败回执中保留。
2. **`round` 凹凸与加去料回执**：`execute_operation_body` 为 `round` 成功回执补齐有符号 `volume_delta_mm3` 与 `round_kind`（`"convex"` / `"concave"` / `"neutral"` / `"unknown"`）并纳入 `compact_sections`。

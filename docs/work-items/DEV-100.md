## 验收

按分项工作卡记录环境与失败原码，保留工作树和实机证据。首先处理法兰几何，其它运行期问题按 P1、P2、P3 推进，既有契约和能力用当前工具实测与源码核对。


## 第一批进展

BUG-186 和 FEAT-084 已完成本机 Creo 10 的 Arm2 毛坯、厚度侧对照、旧调用与回滚验证。BUG-130 的独立作业预算、六个网格阶段与终态诊断已实现并用 Arm2 毛坯验证。原超时样件、Arm7 选边和其它反馈项仍按上表推进。

当前能力核对确认旋转已有真实外部轴引用，可传 `axis` 几何 ID 或 `datum_axis_feature` 标签。报告中的两点式坐标轴和弧度入口仍未支持。显式 `geometry_tolerance_mm` 已在两种求解模式使用同一硬上限，省略字段时的缺省值和超差处理随求解模式变化。

Windows x64 / Python 3.12.10 的 `python tools/dev_check.py --work-item DEV-100` 通过，全量 4497 项，零失败、零错误、7 跳过，三项离线门禁通过。受测基点 `1e2cea90d3337a6401760bf50b7b07a05944f7f5`，dirty=true，源码指纹 `4d143313ef2a134b418b4907b61fc94b93e3829431732a78245f73f60adf6dfe` 与最终 Creo 作业一致。钣金与 STL Python 专项 128 项通过，独立 STL C++ 回归 24 项通过。

源码核对补充。原生 `open_end_samples` 已存在，仍需验证其在失败回执的定位能力；`snap_endpoints` 缺省 false，现有 Python 重写限制两条圆弧的联合改写。`bounding_box_mm` 当前来自 `ProSolidOutlineGet`，尚无精度或计算来源字段。服务自身版本可从 `creo_capabilities` 或 `creo_session_status.server_version` 查询，已连接的 Creo 发版编号来自本次作业的 `creo_release_numeric`。

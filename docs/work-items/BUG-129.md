# BUG-129：组合首壁目标方向缺校验与 Arm2 坐标偏差

## 当前摘要（2026-11-16）

分类：**部分交付，剩余待验收**。类型：缺陷 / 输入坐标契约。优先级：P1。目标版本：未排期。

本批：0.26.0 交付子项（部分交付）加宽度方向断言、回执 `width_direction_world` 与原生质心，拒绝方向冲突；旧 YZ 调用不变。实机 YZ 140×290×1.5 宽向 `[0,0,1]`、bbox `[-60,0,0]–[1.5,140,290]`、质心 `(-8.522,90.538,145)`，期望 `[1,0,0]` 被拒，保存重载通过；见 [实机验收](../development/LIVE-ACCEPTANCE-0250-2026-11-16.md)。Arm2 完整装配逐条对照未做。2026-11-16 追加：收到 61 条原文与 23 条位姿，24 条平面配合可准入、26 条圆配合缺半径/轴、11 条类型未支持；固定位姿合法但缺 Arm2 模型，仍未重建完整件。见 [A2/A0 数据准入](../development/A2-A0-ADMISSION-2026-11-16.md)。

来源：[0.25.0钣金反馈原件](../validation/feedback-0.25.0-2026-11-16/sheetmetal.md)，关联 DEV-090 T3、FEAT-058、FEAT-014；执行范围见[计划M1](../superpowers/plans/2026-11-16-feedback-0250.md#m1arm2-坐标契约与可测方向p1bug-129)。

报告在Creo10保存回读Arm2包络 X[-12,2]/Y[0,8]/Z[0,20]，TXT目标X[-10,10]/Y[-2,8]/Z[-2,12]，局部质心差9.5699mm；23个装配变换一致。本次未重放，不能认定为本机已复现。

源码核对：base_flange沿用通用草绘坐标，YZ的u=+Y/v=+Z，width沿v；现有局部包络与组合体积可以自洽通过。错误可能在输入适配/契约缺失，而非通用plane实现；现有回执已经有frame/envelope/bounds_mm，不重复宣称完全没有方向或包络信息。

## 范围

先冻结旧plane/origin语义、目标方向断言与原生测量回执，定位差异；不静默把旧YZ宽度改到X。真正改变方位需完整placement并查证支撑面法向表达，新增能力开工前另立FEAT。单特征SMBaseFlange、D2改宽与当前两特征组合的几何等价另评估。

## 验收

- 离线：旧调用兼容；方向冲突、非法方向、框架不正交拒绝；投影保留原生方向/bbox/质心。
- 获准后的Creo12.4：先无孔基础组合件核20mm宽度轴、厚度侧及独立冻结包络；再完整Arm2核TXT几何。最终含孔/圆角体积792.323mm³不能作基础件期望。
- 两装配实例按原变换核世界质心；保存重载、失败回滚、revision分别检查。报告降级件1.6647mm误差不视作完成。

当前仅离线资料核对，根因、实机修复、几何等价、Creo10复测均未验证。

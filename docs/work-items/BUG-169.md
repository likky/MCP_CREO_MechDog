# BUG-169：`linear_pattern` 允许非实体/草图 leader 静默空转且 `extrude` 缺少 `feature_id`

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.38.0 已交付并完成本机 Creo 10.0.0.0 实机验收；原案 B025 原始快照、Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.38.0（MINOR）

来源：[0.35.8 反馈原件 §2、§6](../validation/feedback-0.35.8-2026-11-23/originals/linear-pattern-leader-and-through-all-scope.md)。

## 现象与根因

1. **已证实：`extrude` 等特征操作在 `operations[i]` 中缺少 `feature_id`**。`extrude_or_revolve()` 调用 `remember(op, f)` 写入 `aliases[label]["feature_id"] = f.id`，但返回的 `details` 与 `execute_operation_body()` 均未写入 `feature_id`，调用方读取 `operations[1].get("feature_id")` 得到 `null`。
2. **已证实：`linear_pattern` 不校验 leader 类型或是否拥有实体面**。`native/linear_pattern.cpp` 仅检查 `leader_type == PRO_FEAT_GROUP_HEAD`，对 `PRO_FEAT_CURVE`（草图）或基准特征直接调用 `ProPatternCreate`，Creo 会静默创建草图实例（`succeeded=true`、`member_count=7`、ΔV=0.000、无任何警告），且回执只含 `leader_id`、无 `leader_kind` 与 `leader_surface_count`。
3. **未复现部分（如实保留）**：报告 B025（作业 `a8ca9a72…` → `66041948…` → `8e82f379…`）未附原始 `request.json` 与 `model.json`；当前 `native/generic.cpp::feature_id()` 只查 `alias_entry(label)["feature_id"]`，无回退到前驱草图的代码路径。除在运行时复核 alias 与实际 `ProFeatureTypeGet` 一致性外，原案现场需原始请求与模型快照再核实。

## 修复内容

- `native/generic.cpp`：`extrude_or_revolve()` 与 `execute_operation_body()` 为已 `remember(op, f)` 的操作统一写入 `feature_id`。
- `native/linear_pattern.cpp`：在 `ProPatternCreate` 前读取 `leader_type` 与拥有面数（普通特征用 `ProFeatureGeomitemVisit(..., PRO_SURFACE)` + `J::array()` 收集，组头用 `ProFeatureGroupGet` + `ProGroupFeaturesCollect` 汇总成员面数）；拒绝草图/曲线/基准及零实体面 leader（`LINEAR_PATTERN_NON_SOLID_LEADER`）；若字符串 leader 在 `aliases` 中声明为实体操作而原生类型为草图/基准则以 `LINEAR_PATTERN_LEADER_ALIAS_MISMATCH` 拒绝；成功与失败回执均保留 `leader_kind`、`leader_feature_type`、`leader_surface_count`、`leader_surface_query_code`。
- `src/creo_mechdog/schema.py` 与 `generic_bridge.py`：在计划校验与提交准入阶段，若 `linear_pattern` 的字符串 `leader` 指向已知非实体操作（模型 `aliases` 或同计划前置 `sketch`/`airfoil_sketch`/`datum_*`），建作业前直接拒绝 `LINEAR_PATTERN_NON_SOLID_LEADER`。
- `src/creo_mechdog/operation_results.py` 与 `src/creo_mechdog/job_projection.py`：将 `feature_id`、`leader_id`、`leader_kind`、`leader_feature_type`、`leader_surface_count`、`leader_surface_query_code`、`group_leader`、`member_count`、`direction_reference` 纳入 compact 保护/白名单，确保 `creo_get_job(detail="compact")` 与 `detail="full"` 同步披露。
- 附带诊断与文档完善：`src/creo_mechdog/profile_diagnostics.py` 在仅命中 `intersecting`/`tangent` 时不再误导性建议放大 `closure_tolerance_mm`；`docs/REFERENCE_SYNTAX.md` 补齐 `linear_pattern` leader 约束、拉伸切除 `swept_volume ∩ material` 语义与多闭合环边界说明。

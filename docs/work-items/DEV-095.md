# DEV-095：面板准入与回执的可信度披露：model_name、host release 引导与 payload 一致性

分类：**部分交付 0.33.0**（`host_release` 写入与 `unverified_bindings=["payload_sha256"]` 本机 Creo 10 实测；Creo 12.4 未验）。

类型：工程整理

优先级：P1

状态：待验收（2026-11-20 本机 Creo 10 实机通过；Creo 12.4 未验）

目标版本：0.33.0（候选）

来源与关联：0.31.1 反馈“球鼻艏面板 -8”与“交付记录门禁”；关联 [BUG-134](BUG-134.md)、[BUG-135](BUG-135.md)、[DEV-096](DEV-096.md)。

分类依据：待验收——`host_release` 写入与 `unverified_bindings=["payload_sha256"]` 已在本机 Creo 10 实测；Creo 12.4 复测未做。

## 问题或目标

用户与审查者目前无法只凭公开回执判断面板作业的可信边界：回执不写模型名；缺少 host release 时准入文案只拒绝、不引导如何补记录；认证记录与当前部署 payload 是否一致也看不到。结果是只能读源码或靠猜。

## 范围

三项披露改进，均不新增公开工具：

1. 面板块补 `model_name`（`generic_bridge.py`），CONTRACT 不变。
2. `bridge.py` 新增 `record_probe_host_release`：连接成功且 `release_numeric` 为 int 时，把 `{worker_sha256, release_numeric, job_id: None, source: "session_probe", observed_at}` 写入 `build/toolkit_health.json` 的 `host_release`；`panel_profiles.admit()` 的“无记录 host release”文案改为提示先读一次 `creo_session_status`。
3. `panel_profiles.admit()` 对 certified profile 比较认证记录 `environment.payload_sha256` 与当前部署记录 `build/blend_callback_setup.json` 的 `dll_sha256`，不一致或不可读时在 `unverified_bindings` 追加 `"payload_sha256"`；只披露不拒绝，经 `panel_receipt.py` 透出。

不包含：认证 payload 与运行中 DLL 的实时绑定证明、loader 代际选择变更、公开工具新增。

## 实现与证据

变更文件：`generic_bridge.py`、`bridge.py`、`src/creo_mechdog/panel_profiles.py`（`panel_receipt.py` 负责透出）。

离线证据（2026-11-20）：全量单测 4156 项通过、6 项跳过；Ruff `All checks passed`；`bridge.py build` 退出码 0。离线覆盖披露字段与准入文案，不覆盖真实会话写入。

**Creo 10 实机（2026-11-20，本机 `Creo 10.0.0.0` / `release_numeric=42`）**：

- `host_release`：`creo_session_status` 会话探针写入后，`build/toolkit_health.json` 的
  `host_release` 为 `{worker_sha256, release_numeric: 42, job_id, observed_at}`，且后续
  `record_channel_health` 整文件重写时保留该键与 `surface_loft_runtime`（回归单测
  `test_a_status_probe_keeps_the_recorded_release`）。
- payload 披露：面板作业 `7bb73fa98a764818843e85c2e9220b3a` 的准入回执
  `unverified_bindings=["payload_sha256"]`（认证 `3c80bf15…`，部署 `41ad8198…`），
  `mode=certified`、`profile_id=creo10-bbl-candidate-3`；作业仍正常执行并 `succeeded`，
  证明该披露只披露不拒绝；`panel_receipt.profile` 同样带出该披露。
- `model_name`：面板提交回执的 `panel.model_name` 与本作业实际模型名一致（`acc_panel_20261120g`）。

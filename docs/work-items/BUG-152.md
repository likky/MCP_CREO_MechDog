# BUG-152：重复保存与检查点恢复

分类：**已有修复但待验收**。优先级 P1。目标版本为开发分支。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/save-and-loft.md) §1、2、5、6、7，关联 [BUG-113](BUG-113.md)。反馈报告原生保存返回 -1，随后检查点恢复未通过；三个动作的具体触发条件需分别确认。

本机 Creo 10 / Toolkit 42 用简单零件验证三次以上增量提交、单独保存、删后重做、失败后还原检查点。检查实际几何、revision、落盘版本、基线 SHA、恢复后继续写入。Windows 单测验证空 pending 的客户端兼容及非空作业的 stale 拒绝。

已有检查点的独立零件在 Toolkit 确认保存目标为受管目录且没有依赖时调用 `ProMdlSave`。首存与其余既有路径走 `ProMdlnameBackup`。原生保存须新增版本。恢复与回滚先检查同名对象在会话中已消失，读取后验证原生 origin 指向登记的版本文件，再比较几何。

修复前简化圆孔夹具四次保存均成功，第三次必失败的说法未在本机复现。原现场 `Backup=-1` 的触发条件待原始会话证据。见[本次验收记录](../validation/feedback-save-loft-2026-11-23.md)。

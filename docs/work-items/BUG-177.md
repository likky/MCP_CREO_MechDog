- 类型：缺陷
- 优先级：P2

分类：**已有修复但待验收**（0.41.0 已交付并完成本机 Creo 10.0.0.0 实机验收；Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.41.0（MINOR）

来源：[0.39.0 原始反馈（Creo 9 全圆边选择器与面积查询）](../validation/feedback-0.39.0-2026-11-23/originals/creo9-full-circle-edge-selector-and-area-inspection.md) §5、§6。

## 修复内容

1. `src/creo_mechdog/schema.py`：`Arc` 新增可选有符号张角 `sweep_deg`（`0 < |sweep_deg| < 360`，替代 `end_angle` 直接表达 >180° 优弧），校验时换算为标准 `end_angle` 与 `dir` 并在序列化时排除 `sweep_deg`。
2. `src/creo_mechdog/profile_diagnostics.py`：新增 `_sample_catmull_rom` 对 `spline` 进行平滑插值采样，使含 `spline` 的闭合剖面返回数值 `material_area_mm2`（保留 `b_spline`/`ellipse` 为 `unsupported_entities`）。
3. `native/sketch_coordinates.cpp`：`Coordinate dimensioning changed the supplied geometry` 拒绝报错附带 `shifted_sample=`（最多 3 条最大偏移实体/点样本）。
4. `server.py`、`docs/REFERENCE_SYNTAX.md`：在 `creo_create_sketch`、`creo_extrude` 说明与语法文档中写明 `XY`/`XZ`/`YZ` 基准面的 `origin`/`normal`/`u_axis`/`v_axis` 对照表（特别标注 `XZ` 法线为 `-Y`）。

# BUG-167：装配换版没有 replace_component

分类：**待规划**。优先级 P1。来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §十七。

现场只能删掉旧组件再插入新版本，配合关系随之丢失。需要新增 `creo_replace_component`：按 `model_id` 与 `revision` 绑定新版本，使用 `ProAsmcompReplace` 保留约束，保存重载后核对装配体积与约束状态；失败回滚到旧组件。报告 §17.4 给出“装配体积 = 零件体积线性叠加”的校验方法，可作为回归断言。验收：换版后约束仍在、体积符合新旧差值、保存重载；旧版本文件不被改写。未验：报告原始 P05 装配、Creo 9/12。

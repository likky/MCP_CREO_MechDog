# DEV-093：本机实机操作改为常设授权

分类：**已完成 0.31.1**（工程规则：实机操作不再逐次确认）。类型：工程整理。优先级：P2。目标版本：0.31.1。

## 背景

此前按 2026-11-09 的“确认按次生效”规则，启动/重启 Creo、结束进程、清理 `toolkit.lock`、GUI 操作等都要逐次取得用户确认。2026-11-19 用户明确要求这些操作由代理直接执行，无需再问。

## 变更

- `AGENTS.md` 的“本机开发联调补充”改为 2026-11-19 常设授权：可直接新建 Toolkit 连接、启动或重启 Creo 与 nmsd、结束卡死或异常的 Creo/worker 进程、确认后清理残留 `toolkit.lock` 与 unknown 保护状态、编译执行器、建模、GUI 操作（含坐标点击与计算机使用）与几何/保存重载验收；授权自动延续到后续会话。
- “开发准入与台账”中的“实机确认制”表述同步为“实机常设授权”。
- 数据边界保留：不得删除或改写用户模型、历史证据与已发布产物；清理锁或结束进程前先确认无残留 worker，并在证据中记录原因。
- 技术边界不变：Toolkit 单通道、busy 立即拒绝、revision 保护、保存重载核验；开发者单测与 WorkBuddy 黑盒仍分开记录。

## 验证与范围

- 仅改 `AGENTS.md` 与版本文档，未改 Python/原生源码，公开工具仍 109。
- 无 Creo 实机验收项；规则本身不改变产品行为。
- 未验：任务 5 接缝 G1、WorkBuddy 黑盒与旧版 Creo 不受本项影响，仍按各自条目跟踪。

# BUG-189 工具未知参数被静默忽略

分类：**待实现**。缺陷，P2，目标版本未排期。

来源为 [0.43.0 反馈](../validation/feedback-0.43.1-2026-11-24/originals/chamfer-propagate-and-surface-loft-creo10.md) N1。`creo_inspect_model` 把正确参数 `section` 误写成 `sections` 时，返回正常响应、无 error、无 warning，只给出空数据；追加 `bogus_field` 同样被吞掉。报告方因此误判为“模型没有特征”。

当前 `ValidationMCPServer.call_tool` 只在 pydantic 校验失败时清洗错误，没有对 `arguments` 的未知键做检查。

## 范围

- 在 MCP 调用边界用已注册工具的参数 schema 校验键名，未知键返回 `isError=true`。
- 文案至少给出一个可执行的下一步，例如 `unknown argument 'sections'; did you mean 'section'?`。
- 覆盖 `creo_inspect_model`、`creo_capabilities`、`creo_get_job` 等只读工具，以及至少一个建模工具。

## 验收

协议级用例证明：拼写错误与未知字段均被拒绝，合法参数不受影响；`tools/test_mcp.py --offline` 与 `--protocol-only` 通过；不改变任何工具的公开输入 schema。

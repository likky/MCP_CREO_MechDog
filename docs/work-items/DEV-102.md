# DEV-102：整理 `creo_capabilities` 操作列表口径并补全 `region.interior_point_yz_mm` 文档

类型：工程整理。优先级：P2。

分类：**已有修复但待验收**。0.46.0 交付 `creo_capabilities` 操作列表口径整理与 `region.interior_point_yz_mm` 图元限制说明。关联：BUG-151、FEAT-069。 [发布记录](../validation/RELEASE-0.46.0.md)

## 来源与现象

2026-11-26 外部 0.45.1 反馈 §5 与 §6 附注（[原件](../validation/feedback-0.45.1-2026-11-26/originals/draft-flip-loft-arc-weld.md)）。

- `creo_capabilities` compact 同时并列返回 `operations`、`registered_operations`（含 4 个不可用操作）和 `unavailable_operations`，容易被自动化客户端误把 `registered_operations` 当作可调用清单。
- `ExtrudeOp.region` 的 `interior_point_yz_mm` 文档未明确写明其与 `signature_yz_mm` 一样不支持直接作用于 `rectangle`/`circle`/`ellipse` primitive。

## 范围与验收

1. 在 `creo_capabilities` payload 中新增 `registered_but_unavailable_operations`（明确列出 4 个不可用操作）与 `operations_note`，保持既有字段向后兼容并消除误判。
2. 补全 `schema.py` 与 `server.py` 中 `region.interior_point_yz_mm` 对显式 `line`/`arc`/`b_spline` 图元的限制说明。
3. 通过 `tests/unit/test_mcp_contract.py` 与 `tools/test_mcp.py --offline` 离线契约门禁。

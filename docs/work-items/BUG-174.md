# BUG-174：`creo_execute_plan` 内联 `chamfer_type` 丢弃修复、切除去料比例告警、Runner 脱离披露与坐标标注文档

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.40.0 已交付并完成本机 Creo 10.0.0.0 实机验收；外部原始 `frigate_v4` 模型、Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.40.0（MINOR）

来源：[0.35.8 原始反馈（验证挂起与恢复硬限）](../validation/feedback-0.35.8-2026-11-23-hang-recovery/originals/verify-hang-and-recovery-90s-deadlock.md) §4–§6，以及 [0.35.8 原始反馈（三点基准面草图）](../validation/feedback-0.35.8-2026-11-23-hang-recovery/originals/three-point-plane-sketch-reference-and-autodim-misreport.md) §4.4、§10。

## 修复内容

1. `src/creo_mechdog/schema.py`：`dump_plan_operations()` 导出 `ChamferOp` 时保留显式设置的 `chamfer_type`（如 `"d1_d2"`、`"distance_angle"`），修复 `creo_execute_plan(operations=[...])` 内联提交在 `general.submit()` 二次调用 `validate_operations()` 时因 `chamfer_type` 被 `exclude=True` 丢弃而报错的问题；最终传给原生执行器的字典仍剥离 `chamfer_type`，保持既有原生契约不变。
2. `src/creo_mechdog/operation_results.py`、`src/creo_mechdog/compact_sections.py`：为盲切（`extrude mode="cut"`、`depth_type="blind"`）新增只读诊断 `cut_volume_check`（`profile_area_mm2`、`effective_depth_mm`、`expected_prism_volume_mm3`、`actual_removed_mm3`、`removal_ratio`、`low_removal_warning`、`warning_threshold_ratio=0.05`、`note`），支持从同计划草图或模型已登记 `aliases` 解析草图面积，实际去料低于解析棱柱体积 5% 时标记 `low_removal_warning=true`，不回滚合法部分交集切除。
3. `bridge.py`、`generic_bridge.py`、`src/creo_mechdog/reconciliation.py`、`src/creo_mechdog/job_pages.py`：新增 `bridge.spawn_detached_runner()`，Windows 下优先以 `CREATE_NO_WINDOW | CREATE_NEW_PROCESS_GROUP | CREATE_BREAKAWAY_FROM_JOB` 启动后台 runner，遇宿主 Job Object 禁止脱离（`WinError 5`）时回退 `CREATE_NO_WINDOW | CREATE_NEW_PROCESS_GROUP`，并在作业记录与分页摘要中披露 `runner_detached_from_job` 与 `runner_lifecycle_note`。
4. `docs/REFERENCE_SYNTAX.md`：补充坐标尺寸共享顶点/轴对齐共坐标跳过机制、三点斜基准面自动垂直锚定参考与盲切去料比例诊断说明。

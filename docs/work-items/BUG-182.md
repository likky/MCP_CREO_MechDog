# BUG-182：装配面选择器零命中可执行修复建议与坐标空间语义澄清

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.42.0 已交付并完成本机 Creo 10.0.0.0 实机验收；Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.42.0（MINOR）

来源：[0.40.0 原始反馈（Arm7 区域切除仍零命中、G2 仍无几何级验证、全量 60 条配合仍在 arm2_1 零命中）](../validation/feedback-0.40.0-2026-11-24/originals/arm7-region-cut-g2-verification-and-mated-assembly.md) §6。

## 修复内容

1. `native/geometry_selectors.cpp`：为 `nearest_surfaces` 与 `nearest_edges` 每条候选补充可直接复制的 `suggested_reference: {"kind": "surface"|"edge", "id": N}`，并在零命中报错文本中直接列出最近候选 `Closest candidate: {kind:'surface',id:N} (...)`（仍绝不自动选中）。
2. `native/generic.cpp`：当 `requested_coordinate_space="assembly"` 时，在 `geometry_selector_diagnostic` 标注 `nearest_coordinate_space="component"`，并利用 `occurrence_placement` 为每条 `nearest_surfaces` 补充 `assembly_origin_mm` 与 `assembly_normal`/`assembly_axis`，同时在报错文案中说明已将装配坐标换算至组件模型坐标系后检索组件面。

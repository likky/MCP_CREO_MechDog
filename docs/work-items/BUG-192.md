# BUG-192：`draft` 基准面中性面 `flip` 语义与文档相反，缺少加/去料结论字段

类型：缺陷。优先级：P1。

分类：**已有修复但待验收**。0.46.0 交付拔模基准面/实体面方向说明与 `material_effect` 回执；Creo 10 实机 8/8 通过。关联：[BUG-102](BUG-102.md)、[FEAT-051](FEAT-051.md)。 [发布记录](../validation/RELEASE-0.46.0.md)

## 来源与现象

2026-11-26 外部 0.45.1 / Creo 10.0.0.0 反馈 §1（[原件](../validation/feedback-0.45.1-2026-11-26/originals/draft-flip-loft-arc-weld.md)）。

XY 平面圆 R3、沿 +Z 拉伸 2 mm，取 XY 基准面 `datum_plane` 为中性面，拔模圆柱侧面 `+5°`：
- `flip=false`：`applied_pull_vector=[0,0,1]`、`effective_flip=false`、`direction_flip_code=1`，但体积 **+3.362369 mm³（加料）**；
- `flip=true`：`applied_pull_vector=[0,0,-1]`、`effective_flip=true`、`direction_flip_code=-1`，体积 **−3.234121 mm³（去料）**。

工具说明写“对外圆柱凸台，中性面在底部、pull 朝自由端时，正角度会收窄自由端”，与 `datum_plane` 实测相反；且 `BUG-102` 的 `tools/test_draft_direction.py` 当时仅测了实体底面（`surface`）和基准轴，未测 `datum_plane` 作为中性面。

## 范围与验收

1. 在本机 Creo 10 上对 `neutral_plane = surface(底面)` vs `datum_plane(XY)` × `flip=false/true` 做单变量对照，查清几何法向、面朝向与原生拔模方向的对应关系。
2. 修正 `creo_draft` 文档与 `capabilities.families.draft.direction`，明确不同中性面/拉模引用类型的实测方向规则及 `direction_flip_code`（`+1 = PRO_DIRECTION_FLIP_ALONG / effective_flip=false`，`-1 = PRO_DIRECTION_FLIP_AGAINST / effective_flip=true`）含义；如实机发现 `applied_pull_vector` 符号有误则同步修正。
3. 在 `draft` 操作结果中新增由 `material_delta_mm3` 派生的 `material_effect`（`"added"` / `"removed"` / `"unchanged"` / `null`），并在 compact 与 full 回执一致透出。
4. 扩展 `tools/test_draft_direction.py` 覆盖 `datum_plane` 中性面与 `material_effect` 断言，补充 `tests/unit/test_draft_observation.py` 单元测试。

# BUG-154：放样准入与种子几何验证

分类：**已有修复但待验收**。优先级 P1。目标版本为开发分支。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/save-and-loft.md) §4、§9.5，关联 [BUG-120](BUG-120.md) 与 [FEAT-065](FEAT-065.md)。核对三条路径的调用前披露、版本证据与现有替代路线。用与种子尺寸不同的简单截面校验 Creo 10 实机重绑、测量与保存后重载，另测无回调、未验证的内核路径及参数限制的离线回执。

直接 Blend 的回调检查工具进入能力摘要。曲面元素树按同一执行器的 Creo 实测披露准入信息。种子重绑在保存前和重载后核对原生截面依赖、正实体体积及首末平面覆盖。实机两截面矩形、圆、三角形和后续改型通过。

外部七截面种子和完整输入缺失。Creo 10 曲面元素树完成限制及面板路线见 [BUG-135](BUG-135.md) 和 [BUG-120](BUG-120.md)。本次记录见[验收记录](../validation/feedback-save-loft-2026-11-23.md)。

# BUG-184：草图 `geometry_deviation` 逐点位移向量、`compact` 超阈可见性与 `autodim` 容差文档

- 类型：缺陷
- 优先级：P2

分类：**已有修复但待验收**（0.43.0 已交付并通过单元测试与原生构建；Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.43.0（MINOR）

来源：[0.40.0 原始反馈（B 样条除料「零除料」与无法渲染剖面正视图）](../validation/feedback-0.40.0-2026-11-24-bspline-view/originals/bspline-cut-zero-removal-and-section-view.md) §3。

## 修复内容

1. **逐点位移向量**：`native/sketch_coordinates.cpp` 的 `geometry_deviation_stage` 为发生位移的实体条目补充最大位移点角色 `point`、目标坐标 `requested_mm`、实测坐标 `actual_mm` 与位移向量 `delta_mm`；`src/creo_mechdog/geometry_deviation.py` 的 `_normalize_sample` 校验并保留这组字段。
2. **`compact` 超阈可见性**：`src/creo_mechdog/operation_results.py` 在 compact 投影中保留 `warning_threshold_mm`、`enforced`、`tolerance_source`，并在 `exceeds_warning=true` 时附带按偏差降序排列的前 5 条 `displaced_sample`。
3. **`autodim` 强拒说明**：`server.py` 中 `creo_create_sketch` 与 `creo_update_sketch_geometry` 的 `geometry_tolerance_mm` 参数元数据明确标注：显式传入正值时在 `coordinates` 与 `autodim`（含回退路径）均作为硬拒绝门槛执行。

# BUG-162：旋转矩阵 1e-7 准入与六位小数输入冲突

分类：**待规划**。优先级 P1。来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §四。

现场 94 个位姿中 77 个因旋转矩阵不满足 1e-7 被拒；Creo 10 实测 2.241e-7、4.890e-7、1.129e-6 会被 `ProAsmcompAssemble`/`ProAsmcompPositionSet` 以 -2 拒绝，因此不能直接放宽默认值。建议增加显式 `orthonormalize: true`：提交前做 SVD/极分解修正，回执记录修正前后的最大偏差；默认仍严格 1e-7，不静默修改矩阵。验收：修正后位姿可放置、保存重载；未启用时仍拒绝同量级矩阵。未验：报告 94 个位姿、Creo 9/12。

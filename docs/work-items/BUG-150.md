# BUG-150：活动实体的负 ID 与切除诊断

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.35.8 初始实体作用域，Creo 10 已通过）

- 目标版本：0.35.8（初始实体作用域）。原护卫舰零去料待复现。

来源：[0.35.5 原始反馈 §2、§6B](../validation/feedback-0.35.5-2026-11-22/originals/mirror-and-body-id.md)。关联 [BUG-040](BUG-040.md) 的空实体记录、[DEV-081](DEV-081.md) 的切除作用域与 [FEAT-051](FEAT-051.md) 的去料体积回执。

## 现象与范围

外部 Creo 10.0.0.0 / release 42 的 `frigate_v4` rev7 回执把一个有材料、170 个面的活动实体列为 `id=-5778`。另一模型据报返回同值。带该 ID 的切除在提交前被拒绝，不带 `scope` 的拉伸切除则报告去料为零。反馈包没有原始 PRT、完整计划、原生 JSON 或 traceback 附件。包络和板面测量有助于选择复现区域，仍需独立验证实际切削体是否与材料相交。

已发布的 0.35.6 直接输出 `ProSolidBodiesCollect` 返回的 `ProSolidBody.id`，同一句柄还用于读取状态、遍历面和查询包络。该版显式作用域仅接受正整数，省略作用域写入 `PRO_BODY_USE_ALL`。通用 body 解析器把负 ID 转入默认实体分支，显式选中初始实体需要按模型和确切 ID 建立引用。

无作用域分支根据切除前后的整件体积差判定去料，原回执未测量各实体的去料量。实机应先确认全体切除的元素树回读和已知交集试件的体积差，再判定它与负 ID 的关系。

## 验收

- 离线覆盖分页及小型全量巡检。保留历史快照中的 ID、材料、几何和计数，并标识 ID 能否通过现有切除作用域的 ID 校验。
- Creo 10.0.0.0 / release 42 优先复现。比较 body 枚举、默认 body、由成员面反查 body，以及 Creo 界面建立的切除特征树。保存重载后复测同一模型。正 ID 多实体件及无几何负 ID 记录作独立对照。
- 切除对照使用有可计算去料体积的板件和确知不相交的负例。正例验证去料体积、作用域回读、未选实体、revision 和保存重载。负例验证回滚及 revision。现有 `tools/test_cut_scope_live.py` 可复用正 ID 对照，后续补负 ID 夹具。

公开输入与巡检字段见[选择性切除作用域](../REFERENCE_SYNTAX.md#选择性切除作用域dev-081f08)。

## 2026-11-22 修复前实机定位

Creo 10.0.0.0 / release 42 的矩形放样板（模型 `4a84746035064af5b733fa5c8770e887`，建件作业 `11358c9448a94527b13399556c751349`）重现唯一活动体 `-5778`，带材料且有 6 个面，体积 24,000 mm³。带 `scope` 时在 Python 正整数校验被拒。省略 `scope` 的作业 `5aa0366e61dd4e26a4538b2aadb820fe` 成功，体积 23,200 mm³。保存后用只读 C TOOLKIT 探针核对，枚举、默认实体、每个成员面反查、`ProModelitemInit`、选择及引用回读均成功，并返回同一模型的 `PRO_BODY/-5778`。这是 Creo 分配的初始实体 ID。PTC 的首个实体参数示例也使用该编号。[PTC 实体参数示例](https://community.ptc.com/creo-parametric-tips-390/07-multibody-how-to-display-use-or-call-out-a-body-parameter-part-1-131765)

修复范围限于拉伸切除的 `scope`。允许 `-5778` 通过格式校验，原生要求目标模型内确有该活动体，以该 ID 直接构造选择。保留特征树 ID 回读和回滚保护。报告中的无作用域切除未在同类板件复现，原护卫舰模型及完整请求仍待取证。

# FEAT-074：同计划面引用与建模反馈体验

分类：**部分交付，剩余待验收**。优先级 P2。选面、预览与回执交付于 0.36.0，面角色组待验收。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/save-and-loft.md) §8、§9.2–4、§9.6。核对同计划拔模可用的几何选择器与显式面角色需求、轮廓报错的可执行提示与容差、预览的画面覆盖及清理会话的列表契约。用插入前序特征后仍能选中同一个几何面的实机对照验证引用稳定性。

面选择器新增 `feature` 标签，用所属特征和坐标条件在执行时找唯一面。相邻轮廓共边时提示合并外轮廓，端点接近时报告实际间隙和精确连接尺度。零件和装配可用 `jpeg_options` 选择视图与像素规模。会话清单提供可复制的 `erase_target`，实际资格由清理预检确认。证据见[本次验收记录](../validation/feedback-save-loft-2026-11-23.md)。

按侧面/端面角色批量选面、原例弧段的精确输入和跨版本行为尚待验收。

# BUG-160：b_spline 坐标尺寸准入与面积空值

分类：**已有修复但待验收（0.37.0 已交付，剩余现场待验）**。优先级 P0（0.35.5 反馈 P0 批次）。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §五（作业 `d9c78108…`）。`b_spline` 不能与 `dimensioning="coordinates"` 同用；两条 B 样条围成的轮廓 `analysis="partial"` 但 `material_area_mm2=0`，调用方误以为面积真的为零。

根因：`src/creo_mechdog/schema.py` 坐标尺寸允许列表排除了 `b_spline`，而原生创建与坐标维度已支持 `PRO_2D_B_SPLINE`；`profile_diagnostics.py` 对不完整分析仍累加面积，未建模实体贡献 0。

范围：坐标尺寸模式允许精确 `b_spline`（不要求 `approximation_segments`）；存在未支持实体时面积返回 `null`，报告增加 `area_status="unavailable_unsupported_entities"`、`unsupported_entities` 和明确告警；投影保留这些字段。

验收：两条 B 样条首尾相接得到 `analysis="partial"`、面积 `null` 且告警可见；单闭合 B 样条坐标计划通过 schema；完整分析仍返回数值面积。精确闭合样条切除仍归 BUG-153/BUG-165，本轮不承诺。未验：报告原始模型、Creo 9 实机。

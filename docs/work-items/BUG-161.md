# BUG-161：同一整圆的重复边引用导致无信息失败

分类：**开发中**。优先级 P0（0.35.5 反馈 P0 批次）。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §六（失败作业 `39cd30d7…`，单边成功作业 `eb234c14…`）。同一整圆的两段 180° 半圆边（id 116、174）一起提交圆角返回 status 6，且没有 `ProFeatureErrorlist` 明细；单独 116 时整圈倒圆成功，ΔV 与整圆一致。

范围：原生 `generic_round`/倒角公共前置解析每个边引用，取 `ProEdgeInit` + `ProEdgeDataGet`/`ProArcdataGet`，按圆心与半径（1e-6 mm）分组；同组两个及以上引用时在创建特征前明确拒绝，列出 id、圆心、半径并建议保留最小 id。选择器与显式 id 两条路径都经过该前置。

验收：116/174 组合被明确拒绝且不创建特征；只用 116 成功并保存重载。本轮不自动合并引用。未验：报告原始垫板、Creo 9/12。

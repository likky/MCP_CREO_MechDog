# BUG-166：恢复预算固定 90/115 秒与高边数模型死锁

分类：**待规划**。优先级 P1。来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §十五、§十八。

现场 6428 边零件约 0.62 s/边，完整恢复需约 66 分钟；原生 `RecoveryDeadline` 固定 90 s、Python worker 115 s，导致“看门狗杀作业 + 恢复也超时”死锁。BUG-157 已用 `identity` 快速恢复止血并新增 `recovery_phase_seconds`；本项继续做自适应预算：按模型边数/文件大小与已完成的阶段进度计算预算，`full` 模式也可分段续跑，并在回执中给出阶段耗时与剩余预算。验收：高边数零件 `full` 恢复不依赖无限等待，超时前有可判定证据。未验：原始 6428 边模型。

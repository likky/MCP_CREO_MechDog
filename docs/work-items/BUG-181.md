## 修复内容

1. **交叉分割与精确 B 样条细分**：新增 `src/creo_mechdog/sketch_region_split.py`，对直线、圆弧与 clamped B 样条做两两交点求交、T 型端点求交与高斯-牛顿精化，并通过精确 Boehm 节点插入在内部交点处分割 B 样条；无内部交点时保持源实体完全不变。
2. **零命中差异诊断**：`src/creo_mechdog/sketch_regions.py` 接入 `split_intersecting_entities`，零命中时报错输出 `closest_loop=`、`segment_count_diff=`、`max_endpoint_diff_mm=` 与 `detected_loops=`。

## 修复内容

1. `src/creo_mechdog/schema.py`、`src/creo_mechdog/feature_state.py`、`native/feature_state.cpp`、`src/creo_mechdog/compact_sections.py`、`src/creo_mechdog/operation_results.py`：
   - `FeatureStateOp` 新增可选 `include_dependencies: bool = False`（默认 `false` 不变）。
   - `include_dependencies=false` 缺依赖拒绝时在 Python 准入与原生报错中给出可直接复制的 `suggested_targets`。
   - `include_dependencies=true` 时允许自动纳入非系统必需的受影响子特征/伴随基准特征，并在回执中披露 `auto_included_dependencies`。
2. `src/creo_mechdog/component_changes.py`：比较装配组件前后 4×4 变换矩阵引入 `TRANSFORM_NOISE_TOL = 1e-12`，消除 1e-18~1e-17 浮点往返噪声误报 `op="moved"`。
3. `server.py`：`creo_execute_plan` 收到空 `operations=[]` 时经 `invoke` 返回标准 `ToolError`，明确指引使用 `creo_new_assembly` / `creo_new_part` / `creo_new_sheetmetal` / `creo_new_drawing`。

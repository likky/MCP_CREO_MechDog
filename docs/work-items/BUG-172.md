# BUG-172：消除单次作业 10+ 次冗余全量 `inspection()` 与逐边刷盘开销，补齐巡检进度点与迭代上限

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.40.0 已交付并完成本机 Creo 10.0.0.0 实机验收；外部原始 `frigate_v4` 模型、Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.40.0（MINOR）

来源：[0.35.8 原始反馈（验证挂起与恢复硬限）](../validation/feedback-0.35.8-2026-11-23-hang-recovery/originals/verify-hang-and-recovery-90s-deadlock.md) §2，以及 [0.35.8 原始反馈（三点基准面草图）](../validation/feedback-0.35.8-2026-11-23-hang-recovery/originals/three-point-plane-sketch-reference-and-autodim-misreport.md) §8。

## 修复内容

1. `native/generic.cpp` 新增轻量原生查询助手，替换单次作业内不必要的全量 `inspection()`：
   - `find_default_csys_id()`：找到首个 `PRO_FEAT_CSYS` 的 `PRO_CSYS` 即返回 `PRO_TK_E_FOUND` 终止遍历，替代 `resolve({kind:"default_csys"})` 中的全量 `inspection(false)`；
   - `collect_datum_planes_quiet()`：静默收集基准面，替代 `resolve({kind:"datum_plane"})`、`inspection()`、`sketch_frame()`、`sketch()` 中的全量巡检或逐面刷盘 `datum_cb`；
   - `model_has_solid()`：零件找到首个活动体的首个面即终止遍历，替代 `body_options()` 与 `execute_operation_body()` 尾部的全量 `inspection()`；
   - `active_body_count()`：仅枚举 `ProSolidBodiesCollect` 活动体计数，替代 `extrude_or_revolve()` 中的全量 `inspection()`；
   - `check_model_health()`：常规操作尾部仅做 `ProFeatureStatusGet` / `ProFeatureIsIncomplete` 与抑制集核验；仅当发现不健康特征时才回退 `inspection(true)` 采集完整 `failed_features` 并抛相同异常（`resident_panel` 放样仍保留全量 `inspection()` 以计算新增面组）。
2. `inspect_feature` / `inspect_surface` / `inspect_edge` 热循环改用 `check_quiet(code, op, item_id)`（仅在错误时打印 API、错误码与 `item_id`），每 100 个特征 / 100 个面输出 `INSPECT_PROGRESS`（含 `last_id`、`unique_edges`、`half_edges`、`elapsed_ms`），巡检结束输出 `INSPECT_SUMMARY`，并设置 `INSPECT_MAX_FEATURES=200000`、`INSPECT_MAX_SURFACES=500000`、`INSPECT_MAX_HALF_EDGES=5000000` 迭代上限。

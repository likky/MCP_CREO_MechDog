# BUG-163：圆角半径大于相邻角弧半径时缺少几何提示

分类：**待规划**。优先级 P2。来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/geometry-and-assembly-p0.md) §七（失败 `d5ab8ee…`，成功 `9a35844…`）。

现象：P03 顶面 8 条边一次 R12 圆角再生失败；去掉 R11 角弧后成功。当前回执只有 `failed_features.sample=round:p03_fillet`，没有指出“圆角半径大于角弧半径”。建议在圆角前置读取引用边弧半径，`size >= radius` 时给出角弧半径、圆角半径和建议排除的边 id；仍由调用方决定是否排除，不自动改几何。验收：报告同形模型回执包含判断和 id；排除后成功。未验：原始模型与 Creo 9/12。

# BUG-179：`chamfer` 切向链延伸核查/控制、倒角几何回执与 `chamfer_type` 文档说明

- 类型：缺陷
- 优先级：P1

分类：**已有修复但待验收**（0.42.0 已交付并完成本机 Creo 10.0.0.0 实机验收；Creo 9/12 与 WorkBuddy 黑盒未验）

- 目标版本：0.42.0（MINOR）

来源：[0.40.0 原始反馈（护卫舰 chamfer 切向链延伸与 round 失败无诊断）](../validation/feedback-0.40.0-2026-11-24/originals/frigate-chamfer-tangent-chain-and-round-diagnostics.md) §1、§6 P7、§8 问题 1。

## 根因与修复内容

1. **Creo 10 实机核查切向链行为**：`PRO_CURVCOLL_ADD_ONE_INSTR` 本身仅选中单条边（不会沿完整切向链绕过相邻直边），但在开放/相切/斜交端点处，Creo 默认倒角过渡会把倒角平面线性延伸至退出相邻面（90 mm 直边接 R10 圆弧时实测延伸至 `90 + sqrt(51) = 97.141428 mm`、ΔV `-423.0002 mm³`）；若显式追加 `PRO_CURVCOLL_ADD_TANGENT_INSTR`，则会沿完整切向链倒角（实测 `155.707963 mm`、ΔV `-693.6174 mm³`）。
2. **`ChamferOp.propagate` 与倒角几何回执**：`src/creo_mechdog/schema.py` 与 `native/generic.cpp` 为 `ChamferOp` 新增可选 `propagate: "single" | "chain"`（默认 `"single"` 保持既有 `PRO_CURVCOLL_ADD_ONE_INSTR` 行为）；成功回执新增 `created_surface_count`、`created_surface_area_mm2` 与 `chamfered_edge_length_mm`（由新建倒角面实测）并纳入 `compact_sections`。
3. **`ChamferOp.chamfer_type` 字段说明**：保留 `exclude=True` 以维持既有原生载荷契约，并在字段 `description` 中明确标注需经 `dump_plan_operations()` 保留。

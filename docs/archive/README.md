# 历史文档归档说明

本目录用于存放已完成历史使命、不再作为日常开发入口的过程文档，以减少 `docs/` 根目录与主检索路径的噪音：

- `stage-notes/`：早期版本（0.2.x ~ 0.5.x 等）的阶段性进度、修复记录与 WorkBuddy 阶段梳理。
- `superpowers/`：历史开发阶段由 AI 工具生成的实现计划与任务派工草稿。

> 注：受 `creo_mechdog.release_integrity` 及单元测试强约束的 `docs/RELEASE_NOTES_*.md`、`docs/releases/*.json`、`docs/validation/RELEASE-*.md`、`docs/BACKLOG*.md` 与 `docs/work-items/*.md` 仍保留在原路径，未做移动。

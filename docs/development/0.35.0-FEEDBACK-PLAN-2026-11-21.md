## 镜像和加厚引用

镜像面可用 `{"kind":"datum_plane","id":N}`。在 `creo_inspect_model` 指定 `section="datum_planes"` 取得几何 ID；同名基准面的特征 ID 和模型里的计划标签属于不同索引。镜像现有曲面组时使用 `{"kind":"quilt","id":N}`。加厚可用同一曲面组 ID 或带标签的 `quilt_feature` 引用。加厚的 `side="positive"` 沿曲面法线，`side="negative"` 沿反向。如果曲面法线为 +Y，则后者沿 −Y 加厚。

## 原生接口查证

- Creo 10 的本机 `ProCore.h` 把 `ProProcessHandle` 声明为 `PeerIdx`。Toolkit 能从自己的连接句柄提取 ID，但没有从 Windows PID 转换的依据。发现路线验证前，保留 `selection_required`。 [PTC 的连接 ID API](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/korean/creo_toolkit/api/dita/489.html)
- PTC Object Toolkit 的 `ConnectById` 也要求已知 ID。同一用户及显示终端出现多个匹配时，普通连接会报告歧义。后续先验证已有连接的 ID 能否由受管会话主动登记、失效后能否及时剔除，再评估未登记会话的发现方式。 [PTC Object Toolkit 连接类](https://support.ptc.com/help/creo_toolkit/otk_cpp_pma/r13/usascii/creo_toolkit/api/dita/t-pfcAsyncConnection-AsyncConnection.html)
- 文档确认 `ProSolidMassPropertyWithDensityGet` 接受零件或装配，并可使用指定或材质密度。装配候选以该原生接口对照，混合密度时几何重心与质量重心分别测量。 [PTC 的质量属性说明](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/chinese_cn/creo_toolkit/Mass_Properties.html)

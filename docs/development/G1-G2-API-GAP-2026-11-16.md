# 选区签名与 G2 圆角的原生 API 查证（2026-11-16）

对象：本机 Creo 12.4.0.0 的 C TOOLKIT 头文件（`Common Files/protoolkit/includes`）与官方联机帮助。
边界：第 1、3 节以静态查证为主；第 2 节在 2026-11-16 按当次授权完成原生构建与实机探针，
探针只新建测试块，不触碰用户模型、不结束进程、不清锁。

## 1. G1 区域切除：仍缺“选中已有区域”的接口

- `ProExtrude.h` 中没有 `region` / `Region` / `REGION` 任何匹配，也没有 `ProExtrude*` 原生函数；
  拉伸特征仍走元素树。
- 全头文件中 `PRO_E_*REGION*` 只出现在制造/晶格类枚举，不属于实体拉伸的草图区域选择。
- `ProSection.h` 提供的是构造/遍历轮廓的接口，不是“按边界签名识别并选中已有闭合区域”；
  它也不能表达 TXT 要求的“输出侧与区域选取一致”。
- `ProSurfReg.h` 里确实有 “Surface Region”，但元素表写明它是 `PRO_FEAT_SPLIT_SURF`：
  用草图（`PRO_SURFREG_SKETCH`）或链（`PRO_SURFREG_CHAIN`）**分割已有曲面**，输入是
  “被分割曲面集合”，不是“在拉伸里选中草图的闭合区域”，也不能直接产生实体切除。

因此 `src/creo_mechdog/region_selection.py` 目前只做三件事：解析 `[B-REGION]` 的
`signature_yz_mm`、经 sketch frame 把局部 `(u,v)` 映射为全局 `(y,z)`、在候选区域中做唯一匹配
（0 命中/多命中都拒绝）。它**没有**接入 `ExtrudeOp`，`region_index_hint` 不参与选择。
真实能力仍缺以下原生证据：

1. 草图闭合区域如何获得可稳定复选的 Creo 标识（或元素树里的区域选择项）；
2. 选中区域后，切除方向/输出侧如何与签名一一对应；
3. 保存并重开后，同一签名是否仍解析到同一区域。

在上述三点有实机证据前，区域切除保持不开放。

## 2. G2 实体圆角：已实机验证（2026-11-16）

已发布结论“`ProRound.h` 没有曲率连续字段”需要修正为更准确的表述：

- `ProRoundShapeType` 确实只有 `CONSTANT/VARIABLE/FULL/THROUGH_CURVE/CHORDAL`，没有 G2；
- 但同一头文件的 `ProRoundConicType` 声明了：

  ```c
  PRO_ROUND_CONIC_ENABLE        = 1,
  PRO_ROUND_CONIC_DISABLE       = 2,
  PRO_ROUND_CURV_CONTINUOUS     = 3
  ```

  即“曲率连续（G2）锥面圆角”是一个已声明的枚举值。
- 同文件的元素表只规定 `PRO_E_RNDCH_CONIC_VALUE` / `PRO_E_RNDCH_CONIC_DEP_OPT` 在
  `PRO_ROUND_CONIC_ENABLE` 时必填，没有说明值为 3 时需要哪些子元素，也没有说明实体边是否接受。
- 2026-11-16 追加：本机安装的官方联机帮助
  `online_help/creo_toolkit/user_guide/Element_Details_of_PRO_E_RNDCH_SET_for_Round.html`
  明确写了 `PRO_ROUND_CURV_CONTINUOUS — Used to specify curvature continuous rounds`，
  并再次说明 `PRO_E_RNDCH_CONIC_VALUE` / `DEP_OPT` 只在 `PRO_ROUND_CONIC_ENABLE` 时必填。
  `ProModifyRound.h` 也把 `PRO_MODRND_CONIC_D_X_D_C2` 映射到同一个值（C2）。
  所以“值 3 不需要 conic value/dep opt”有官方文档依据，但**仍未写入过元素树，也未实机**。

### 实机结果（2026-11-16 19:48，Creo 12.4.0.0）

- 报告：`build/live_g2/20261116T194830_ca3b1511/report.json`，
  SHA256 `ebb7f19bd50fb8bf240372990a121374595d3dd19c3a9877a98d0fc68488b153`
- 用例：两个新建 100×80×20 块，同一相对竖边（id 64，z=0→20）倒 R5。
- G2（`curvature_continuous=true`，写 `PRO_ROUND_CURV_CONTINUOUS`）：
  `succeeded`、`effect_status=committed`、保存重载通过，回执回显
  `curvature_continuous=true`；体积 `159 999.99999999997 → 159 919.92072439735`，
  去除 `80.07927560262033 mm³`。
- 圆弧基线（不写该值）：同样成功，体积 `159 999.99999999997 → 159 892.6984634967`，
  去除 `107.30153650327702 mm³`。
- 两者去除体积相差约 27%，且基线值与 R5 圆角的解析估算一致，说明 G2 分支**没有被内核
  静默退化成普通圆角**；`reference_application` 为 1/1、`source=feature_tree`。

结论：`PRO_E_RNDCH_CONIC_TYPE=PRO_ROUND_CURV_CONTINUOUS` 可由
`ProFeatureWithoptionsCreate` 接受并生成保存后可重载的圆角。因此 `RoundOp` 增加可选
`curvature_continuous`（默认不写，保持原有行为）。限制：本轮没有直接读取曲率连续性，
“G2 vs 圆弧”的区分依据是去除体积与解析值；未测 Creo 10/9、凹边、变半径与多边组合。

# BUG-120：T1-C 补证与面板结束验证

日期：2026-11-17。用途：转交能访问朋友那台 Creo 10 的开发 agent。属于开发者取样，不是 WorkBuddy 仅 MCP 黑盒验收。先执行下面的离线部分；涉及编译、Toolkit 或 GUI 的部分，由机主明确同意本轮范围后执行。

用户目标是把已成功的按 ID 建面方法接入正式 MCP，最终创建球鼻艏。现有 T1-B 已证明一条值得继续的路线，但下面的结束状态和几何证据还没有收齐。不要重做全部六个矩形案例，也不要把本任务扩展到 STL。

## 已有结果与本次范围

- 完整包 `2026-11-17_t1b_id_driven_blend/` 的六份 PRT 字节数/SHA256 与报告一致；六组按 ID 选择的原始日志与汇总一致。
- 三、五截面的包围盒偏差约 0.120005mm，仍是未通过项，不放宽原容差。
- 包内没有六份 `inspection-verified-*.json` 和六份面组测量 `job.json`。矩阵来自包外数据，不能把矩阵本身当成独立测量原件。
- 探针的 `Done` 预先排在宏尾，选取回调失败也可能继续提交；静态 identity、回调次数和宏返回0均不能单独证明成面或面板退出。
- 正式 MCP 新建面后端尚未接入。现有离线改动只修旧路线的观测准入和未来面板未知状态的保护，不代表 Creo 10 球鼻艏已经修复。

## 可直接转交的任务提示词

你要继续 BUG-120 的 T1-C 开发取样。请先读取本机项目 AGENTS.md，沿用当前 T1-B 原件，不修改原始模型、日志或报告。本轮先补齐原件并检查结束流程；没有本轮实机授权时只做第一步。不要结束/重启 Creo 或 nmsd，不清锁、不清 unknown，不覆盖已加载 DLL，不进行故障注入；通道不健康或界面状态不确定时停止后续建模，记录现场。

### 1. 离线补齐原始回执，不需要连接 Creo

定位本机的 T1-B 测试目录和保存这些测试作业的 MCP 仓库根目录，确认后运行随包的 `review_t1b_package.py`：

```powershell
python review_t1b_package.py --package '<本机T1-B目录>' --output '<新的补证输出目录>' --receipt-root '<含models和jobs的MCP根目录>'
```

脚本只按矩阵里的受管模型 ID、快照名和测量作业 ID 收集指定原件，输出 `audit.json`、`package_manifest.json`、`receipt_manifest.json` 和 `receipts/`。`present`只表示指定路径的文件已收集，`identity_verification=not_checked`表示内容里的模型/作业/特征关联还未核对，不能算几何验证。路径不存在时记缺失，不能伪造或重新生成同名原件。已有输出内容不同时换新目录，不能覆盖历史证据。

此外，按六个 `adopted_model_id` 查找已有收养 inspect/apply 作业的原始请求和结果，逐份保留 `saved_file_reloaded_and_verified`、`source_unchanged` 及原始告警。查到哪些就提供哪些，不用摘要代替。不复制 SDK、许可、服务配置或无关用户文件。

将原件与矩阵逐项比对。面组必须关联本次新增 feature_id，不能直接取第一个 quilt。父引用只能作为依赖集合证据，不能把其数组顺序当作采集器顺序。先输出缺失项和差异，再进行下一步。

### 2. 获本轮实机授权后，查清 0.12mm 的原因

使用三截面或五截面的另存测试副本，测四条边界的实际端点、边界范围及面是否位于 Z=0；同时记录当前 bbox 字段的 API 来源。原 bbox 是 `ProSurfaceDataGet` 的 `xyz_min/xyz_max` 合并值，不等同于已经测过裁剪边界的极值。

区分“数据结构给出的包围范围带余量”和“几何确实偏移”。仅面积800、周长120不足以定因。对曲面内部的采样只能称抽样，不能假称精确极值；无法完成可靠比较就保留未验证，不修改原测试的 `bbox_ok=false`。

### 3. 取得可用的取消流程和完成观察

使用临时模型副本。先用 GUI 录制真实的边界混合取消操作：界面✖、确认框和返回模型界面的完整序列，保存独立 mapkey/trail，不覆盖 config.pro。不要继续使用已经证明无效的 `dashInst0.Cancel`，也不要猜控件名。

回放只采用本机实际录制的流程，并分别记录：面板是否关闭、确认框是否消失、是否没有新增特征、后续一次合法请求是否正常。面板未退出时不得重生成、保存、收养或重载模型。

在新的临时探针源码中增加选取失败锁定和受控完成步骤：准备时绑定请求/模型/引用；按请求位置记录一次选择；失败后不继续选取、不自动重试 TOGGLE、不发送 Done。不要再从任意输入接收宏文本。只有所有选取步骤成功后才允许尝试完成，并用结束后的独立标记、界面退出观察、新增完整特征和几何共同判断结果。这个修改是待验证探针，不是正式 MCP 后端。

新 DLL 必须使用独立文件名/目录，并按实际注册要求由机主完成必要操作；无法安全加载就记录未运行，不覆盖正在使用的 DLL，也不以此为由擅自重启 Creo。

### 4. 增加一个能看出中间截面作用的最小案例

在三条平行直线的案例中，把中间一条线抬高，例如 Z=3mm，两端仍为 Z=0。按空间次序提供截面，但让特征创建次序与空间次序不同。确认真实采集器行记录以及生成曲面确实经过中间曲线；仅父引用列表和回调成功码不算顺序观察。

本步只验证第一方向。第二方向、尖点和真实球鼻艏没有做就保持未验证，不顺便宣告通过。没有可靠的面板结束判断时先停止在第三步。

### 5. 打包返回

保留旧包不动。新目录含：原始回执、文件SHA256清单、修改后的探针源码及编译日志、实际mapkey/trail、逐项选取/完成/取消日志、必要的新PRT、测试环境与源码身份、简短结论。两次历史恢复分开记录：首次阻塞由机主重启恢复，后一次取消异常关闭对话框后恢复。

分别写清：原件补齐情况、bbox原因是否已证明、取消是否自动成功、失败是否阻止Done、完成是否有独立观察、中间截面是否真正影响形状、仍未验证的范围。不要把“试验通过”写成“正式MCP已修复”。

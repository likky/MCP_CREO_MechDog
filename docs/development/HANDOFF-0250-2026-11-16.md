## 1. A2：61 条 `[B-MATE]` 完整约束集

**缺什么**：逐条原始参数与组件映射。本机没有增强版 TXT，也没有测试机工作区的
`creo_plans_v0250`。现有资料只有汇总（`concentric 26 / coincident 24 / parallel 6 /
distance 4 / gear 1`）和两条样例（`n24`、`n25`），不足以实现和验收。

**需要的数据（优先级从高到低）**：

1. 测试用增强版 TXT（含 `[B-MATE]` / `[B-MENT]` / `[B-COMP]` / `[B-REGION]` / `[B-GEO]` /
   `[B-FILLET2]`），即反馈所说“第 830–843 行起共 61 条”的版本；
2. 测试机 `creo_plans_v0250/mates_preserved.json`（61 条原文）；
3. `creo_plans_v0250/assembly_ops_v0250.json`（23 组件与 transform）；
4. 可选：`mates_evaluation_v0250.json`、`manifest.json`、`edge_anchors.json`。

放置位置：直接作为对话附件，或复制到 `build/incoming/`。这些是源数据，只读用于生成/核对
配合计划，不入发布包，不改用户模型。

**拿到后的步骤**：

1. 解析 `[B-MATE]` 的 `type / sides(n1,n2) / type=plane|circle / near / dir / axis / radius`，
   以及 `[B-MENT]` 每侧锚点；按 id 与 `[B-COMP]` 组件表建立映射；
2. 平面锚点 → `geometry_selector(target=surface, points_mm=near, axis=dir)`；
   圆锚点 → `geometry_selector(target=surface, center_mm, radius_mm, axis)`；
   点/边锚点仍不支持的（如 `gear`、`parallel`、`distance`）按类型拒绝，不近似；
3. 先离线生成计划并做零/多命中预检，再在当次授权下实机；逐条记录 `built / preserved / rejected`；
4. 验收：每条配合的真实类型、两侧引用、实际 transform；保存/擦除/重载一致；失败必须回滚且
   总装不残留半成品。

**涉及**：[assembly_constraints.py](../../src/creo_mechdog/assembly_constraints.py)、
[advanced.cpp](../../native/advanced.cpp)、
[assembly.md](../validation/feedback-0.25.0-2026-11-16/assembly.md) A7。

# BUG-120 实现计划：导线预检与建面回执

> **For agentic workers:** 使用 `subagent-driven-development` 或 `executing-plans` 分批实施。目标机开发任务，WorkBuddy 黑盒验收另行执行。

**Goal:** 把 Creo 10 已跑通的真实三导线曲面和完整实体变成可复现的回归。先让 MCP 在放样前指出有证据的曲线配合问题，成功后自动给出与本次作业绑定的几何回执；接缝光顺单独验证。

**Architecture:** 沿用 stdio → Python 准入 → 单通道 native worker → `resident_panel`。输入形态在 Python 静态校验；曲线配合在 worker 读取已求解的 Creo 几何后、打开面板前检查；只用可追溯的原生检查结果填回执。首批不新增公开工具，不改回调宏或协议。

**Tech Stack:** Python 3.12+、Pydantic、unittest；C++17 与目标机 Creo 10 C TOOLKIT。复用本机 SDK、MSVC 和现有构建/配置。

**Spec:** [BUG-120](../../work-items/BUG-120.md)、[既有面板方案](2026-11-17-bug120-resident-panel-implementation.md)、[工程验收](../../development/CREO_MODELING_ACCEPTANCE.md)、[PTC Creo 10 双方向边界混合规则](https://support.ptc.com/help/creo/creo_pma/r10.0/usascii/surfacing/surface/About_Boundary_Blend_Reference_Entities.html)。本计划更新真实球鼻艏案例的任务状态；旧架构、注册和历史证据继续保留。

## 开发任务

### 1. 修正错输入比面板更早报错

- [ ] 复现 `creo_surface_loft` 与 `creo_execute_plan` 共用的字符串引用和 `open_confirmed` 契约。查 `src/creo_mechdog/surface_ops.py`、`generic_bridge.py` 和 `native/panel_run.h`；使用已证明的开曲线事实，或对缺少开闭证明的 `resident_panel` 引用给出可操作的静态错误。不能无依据自动补 true。同步修正工具说明和示例；点引用例外、旧元素树请求照旧。
- [ ] 单测证明裸字符串等缺证明输入在获取通道、创建作业或保留面板 guard 前被拒；合法对象通过，默认 `element_tree` 行为不变。覆盖两个公开入口走同一校验。

### 2. 先加原生诊断，再根据证据决定哪些能拦

- [ ] 在 `native/panel_references_sdk.h` 解析实际归属与单曲线引用的基础上，新增独立的小型原生诊断实现；接在 `native/panel_run.h` 解析完成后、Prepare 或提交宏之前。用目标 Creo 10 SDK 核准参数域、坐标框架、返回码和单位转换。优先复用已验证的求值/端点方法；不要仅从输入控制点或 `native_section` 本地坐标猜原生交点。
- [ ] 对真实件报告 21 对曲线：角色、标签、实际 feature/curve ID、测量状态、方法、位置、参数、间隙毫米值及原始码。分开查“首末截面与外侧导线能否闭合”“中间截面的配合”“曲线方向和穿过顺序”。允许曲线越过交点由 Creo 裁切；端点不重合不等于无交点。采样未找到、查询失败、模型单位未知等记 `unverified`，不能写零也不能直接说不相交。首批只拦有可靠证据证明不符合规则的输入；不把输入的 0.043 mm 写成所有模型的阈值，不预测 Creo 是否必然再生。诊断受现有通道和时间预算约束。
- [ ] 静态拒绝与 worker 内、但未开面板的原生拒绝分开。后者仅凭绑定作业、会话与 nonce 的正向证据，证明未打开面板、未改变检查点或已验证恢复，才允许正常失败并退役本任务的 UI guard；即使面板未开，多操作计划可能已有操作，不能整单假定无变更。开面板后超时、缺原生回执或结束未确认时保留 `unknown_outcome`。禁止用日志里“没看到宏”或 PID 消失替代证明。正反例覆盖 `tests/unit/test_surface_loft_panel_admission.py`、`test_panel_execution_unknown.py` 与 `test_panel_session_guard.py`。

### 3. 成功回执要能定位并量到实际面组

- [ ] 从建模前后的原生 inspection 和保存重载核验中，唯一关联新放样 feature → 实际 quilt；使用现有测量实现（可参照 `native/surface_measure.h`）返回面积、是否开放和边界记录。不要把 `selection_intent`、第一个 quilt 或 `selected=10` 当实际引用证明。
- [ ] 在 `src/creo_mechdog/panel_receipt.py` 让“面板退出、写作业提交、几何实测”各自可读。只有真实正面积、目标面组关联和保存重载后读数齐备才填 `geometry_check.verified=true`；缺项保留 `unverified` 并指出原因。成功件已有的事务语义不因后来只读测量失败而被悄悄改写。主回执放简明结论，完整版通过现有分段查询，验证新增/既有面组、测量失败和证据缺失等分支。

### 4. 把 B 和 C 分别做成曲面、实体回归

- [ ] 先跑原生规则/专项单测和适用的 `tools/dev_check.py`；需要编译的步骤按本轮授权执行。实机确认 Creo 10 / release 42、认证 profile `creo10-bbl-candidate-3`、回调就绪、执行器身份与源码一致。使用新测试件或干净副本，保留 A/B/C 原件与保护。busy 立即返回；已接收的作业只轮询。
- [ ] 基础正例用已知能成面的曲线网络；确定断开的外边界负例要在开面板前给出具体引用及原因，基线 revision/SHA256 不变。另测仅“未知”而没有确凿负证据的场景，不能误拒。
- [ ] B 正例由 01 → 09 → 10 在新件重现。确认退出、保存重载、一个唯一关联本次特征的新增开放面组、一面四边，面积和四边长度与上面的原始证据对照。先记录重复测量与核准的比对容差，不把历史报表的小数位数当允许偏差。用保存重载后的独立测量交叉验证新回执；ID 现场查，不硬编码 136/142。
- [ ] C 作整链正例：采用本轮 B 正例生成件或采用 SHA 绑定的历史 B 副本，报告使用的是哪一种。参照 C0–C8 的作业输入：采用 → 艏段几何与点收敛放样 → 拼合半壳 → 以实际 quilt 引用镜像 → 左右拼合 → 后端平盖与拼合 → 实体化。面组/面 ID 由当轮结果解析。验封盖后 0 开放边、14 条共享边，最终一个有材料的实体、保存重载，体积与 **55.0870381358 m³** 的基线对照并报告偏差。完整模型介入较多时可先提交任务 1–3 的结果和 B 实测，再补 C；没重测就标记 C 为历史基线。C 当前的 G1 未通过和重叠未验证要继续披露。
- [ ] 对原 02b 先做只读诊断；是否前置拒绝由证据决定，不因历史失败强制拒绝。若只靠曲线诊断尚不能定位，且确有必要并有当次实机授权，用独立副本比较“只反转原 B 样条方向，保持其几何不动”与“保持方向，使用穿点导线”的单变量对照。必要时进一步按一条导线一项变化拆分；不要求重放已经留有原件的失败。记录未经验证的假设。
- [ ] 交付改动、测试报告、基础与真实件的作业原件、SDK/worker/loader/回调身份、参数域与单位、模型与验证文件 SHA256。开发回归与 WorkBuddy 黑盒结果分开；更新现有 BUG-120 工作卡和能力说明，不自动合并或发布。

### 5. 后续独立验证：让接缝两侧的切线接顺

- [ ] 先用现有 `creo_measure_surface_curvature` 在 C 副本或可追溯的同阶段重建件复核 X=76000 mm 接缝，按面归属和边的位置定位，不用固定 ID。以当前 17 点方法作对照，再核两端与龙骨附近；新增测点记录数量、覆盖范围和方法。把“边接上”“角度接顺”“形状还像”三个判断分开。
- [ ] [Creo 10 原生界面文档](https://support.ptc.com/help/creo/creo_pma/r10.0/usascii/surfacing/surface/To_Define_Boundary_Conditions.html)有以邻接面为参考设置 Tangent 的入口；这不是现有 `resident_panel` 已支持。获准后先在新小样验证“以接缝边和后段邻接面作参考，显式切向，带末端点”的真实界面组合；记录实际可选对象、是否能再生、保存重载和角度。若组合不可用，分别对照只用切向、只用点，再评估独立过渡片或其他有实证的原生路线；不回退到已知受阻的元素树，也不从 12.4 案例外推。
- [ ] 小样通过才在独立副本验证真实件。锁定 B 后段和原尖点，记录新艏段/过渡片做过哪些变化。保留原接缝基线，沿新接缝测角度，目标是本案例样本最大 ≤0.5°，同时核验闭合、保存重载和重点区域外形。外形需和同坐标下的原件或明确注明来源的参考面做逐点距离/站位比较；未取得参考面时不要用包围盒三点 RMS 代替。若结果可稳定重现，再另立实现方案讨论受控的面板切向参数、认证和发布；小样失败不阻塞任务 1–4。

本批不自动吸附、删导线、重拟合或反转用户曲线。需要派生输入时另存并报告偏差；不要把球鼻艏名称、站位或 ID 写入通用逻辑。镜像崩溃、STL、自动装载回调与发布均不并入本批。

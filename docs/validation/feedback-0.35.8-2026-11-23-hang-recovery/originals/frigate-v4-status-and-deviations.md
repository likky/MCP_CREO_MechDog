## 5 个斜基准面草图的做法（rev75–87）

这三个阶段是必须分开的，任一阶段跳过都拿不到可解的 section：

1. **`planes`**：TXT 给的 `(平面过点, 正向法线)` → 取 `n = unit(法线)`、`seed = 与 n 最不平行的世界轴`、`u = unit(cross(seed, n))`、`v = cross(n, u)`。三点取 `O`、`O+100u`、`O+100v`，`cross(100u,100v)=10000(v×n)... = +n`，所以 Creo 返回的 `plane_frame.normal` 必等于 `+n`（实测 5/5 `dot=1.0`、`verified=true`、`max_point_distance ≤ 3.6e-15 mm`）。但 `through_points_plane` 只校验 `|dot|≈1`、两符号都放行，**必须读回 `plane_frame.normal` 再决定草图 v 轴符号**。
2. **`anchors`**：`ProSectionEntityFromProjection` 对本机 101/101、107/107 个基准面返回 `-2`，所以 section 只有一条参考 → `SKETCH_SOLVE=-1`、救援 `ProSectionAutodim` 也 −1，对外只报 `AutodimensionSketch failed with code -1`（报错点不是根因点，详见同名反馈文档）。绕法是补一条「法向 = u、过轮廓形心」的基准面：三点 `P0=O+uc·u+vc·v`、`P0+100v`、`P0+100n`，其与支撑面的交线是 `u=uc`，既轴对齐又穿过轮廓，两条参考都成立、`pin_coordinate_origin` 两轴都能 pin。
3. **`build`**：每环一条 sketch + 一条 extrude。`depth = TXT深度 × 100`；`depth2` 存在时按相反 `direction` 再拉一次。含椭圆弧/样条的环降级为一条闭合 polyline（`coordinates` 不接受 `b_spline`，`Ellipse` 只有轴对齐整椭圆）。

生成器 `_gen_inclined.py`（三阶段 CLI）、回读核对 `_verify_incl.py`。

## 关键实测事实（0.35.8 新增）

1. **`-5778` 可用，但不是所有零件的初始实体都是 −5778**：同一会话里用 `creo_execute_plan` 新建的 200 mm 块体返回 `id=52`。作用域每次都要从 `bodies[].id` 取。
2. **切除引擎按「扫掠体 ∩ 材料」计**：探针件 Ø50×150 从实体外 100 mm 切入，只去料 π·625·50 = 98,174.7704。所以「小于截面×深度」属正常，不是漏切。
3. **`through_all` 不能带 `scope`**（提交前拒绝）；`through_all` 回执无有效深度区间（`through_all_has_no_finite_depth`）。
4. **`linear_pattern` 的 leader 可能解析到前驱草图**：回执 `leader_id` 会是草图 ID，`member_count` 照常返回、`succeeded=true`，但体积变化为 0。用法上每次读 `leader_id` 并与 `aliases` 里的 `feature_id` 比对。
5. **`feature_state delete` 的依赖保护有效**：删阵列会连带列出其前驱草图，拒绝执行且整批回滚（revision 不变）。
6. **`sweep` 的 `arc.dir` 语义**：`dir` 相对草图平面法线，与平面 `offset` 正负无关；XZ 草图从 `offset=−665` 换到 `+665` 时 `dir` 保持 `+1`。
7. **`verify_model_start`（全模型巡检）是每个作业的真实成本**：474 特征时 220–547 s，日志里是 `ProSolidFeatVisit` + `ProSurfaceContourVisit`×10,027 + `ProEdgeIdGet`×64,392 逐条打印。看门狗判的是「日志停止增长 600 s」，所以耗时本身不致命；致命的是**某个 Toolkit 调用不返回**（D18）。单次成功提交整程 8–12 min，规划批量时要按此估时。
8. **`through_points` 基准面的法向只校验 `|dot|≈1`**：两个符号都算通过，`verified=true` 不代表方向对。斜置草图必须读回 `plane_frame.normal`（见 D17）。

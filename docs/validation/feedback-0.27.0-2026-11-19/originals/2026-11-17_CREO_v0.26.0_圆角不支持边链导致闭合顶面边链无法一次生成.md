# CREO MCP v0.26.0 问题反馈：圆角不支持边链，闭合顶面边链无法一次生成

- 日期：2026-11-17
- MCP：`MCP_CREO_MechDog`
- 版本：`v0.26.0`（`version.py` = `0.26.0`，git tag `v0.26.0-2-gef02f07`）
- Creo：本机 Creo，内核报告 `creo_release_numeric=41`
- 问题级别：P1 / 几何能力缺口
- 核心问题：`creo_round` / `execute_plan(op="round")` 只能对“单个边”或“一对相邻面”建立一个圆角集合，不能把相邻边作为一条边链传给 Creo；因此文本要求的一次性 R12 顶面 8 边闭合圆角无法生成。

## 3. 根因分析

### 3.1 公开能力表已声明缺失

`src/creo_mechdog/capabilities.py` 中对该能力的描述包含：

```text
"condition": "edge-chain, variable radius, full/transition or non-adjacent faces",
"effect": "constant radius on two adjacent faces only; no edge-chain input",
```

以及：

```text
"multi-set or solid target; edge-chain input is not accepted ..."
```

`creo_surface_round` 的工具说明也明确：

```text
edge chains, transitions and multiple sets are refused before a job exists
```

### 3.2 原生实现每个 reference 只建一个圆角集合

`native/generic.cpp` 的 `generic_round()`：

```cpp
ProElement sets = node(root, PRO_E_RNDCH_SETS);
for (auto refs : op["references"]) {
    ProElement set = node(sets, PRO_E_RNDCH_SET);
    ...
    ProSelection e = resolve(refs.at("edge"));
    curve_collection(node(r, PRO_E_STD_CURVE_COLLECTION_APPL), J::array({refs.at("edge")}));
}
```

即：每传一个 `{"edge": ...}` 就创建一个独立的 `PRO_E_RNDCH_SET`，每个集合只有一条边。传入 8 条边会变成 8 个互不相干的 R12 圆角集合；相邻圆角在角部冲突，Creo 重生成状态 6。

### 3.3 当前 schema 没有边链表单形式

`src/creo_mechdog/schema.py` 中：

```python
class RoundOp(StrictModel):
    references: Annotated[list[dict[str, Any]], Field(min_length=1, max_length=100)]
```

`src/creo_mechdog/geometry_selectors.py` 的 `validate_reference_list()` 只识别：

- `{"edge": selector}`
- `{"surfaces": [selector, selector]}`

没有 `edges` / `edge_chain` / 有序边链 / 自动邻接链等可以让一个 `PRO_E_RNDCH_SET` 持有多条边的输入形式。

## 4. 实际影响

- 文本中的 P03 `F02 P03 R12` 是顶面闭合边链圆角，当前 MCP 无法用 `round` 直接重建。
- 这不是半径过大或选边错误：选择器已经成功匹配顶面 8 边，失败发生在原生圆角特征重生成。
- 该限制会影响任何“沿一圈/一条链倒同一圆角”的机械零件，尤其是封闭轮廓顶边、长圆槽外圈、环形凸台外圈等。
- 本机 v0.26.0 已确认旧版 `verify_model_save` 卡死问题修复；保存/回滚均正常，本次是独立的几何能力缺口。

---

## 5. 希望增加的能力

建议任选其一：

1. **边链输入**：允许一个圆角集合携带多条相邻边，例如：

   ```json
   {
     "op": "round",
     "label": "p03_fillet",
     "size": 12,
     "references": [
       {"edge_chain": [
         {"kind": "geometry_selector", ...},
         {"kind": "geometry_selector", ...}
       ]}
     ]
   }
   ```

   原生侧应把它们写入同一个 `PRO_E_RNDCH_SET` 的 `PRO_E_STD_CURVE_COLLECTION_APPL`，而不是拆成多个集合。

2. **自动闭合链选项**：选中一条边后，沿相切连续边自动扩展成完整链，例如：

   ```json
   {"edge": {...}, "propagation": "tangent"}
   ```

3. **面边界圆角**：允许用“顶面 + 侧面集合”或“顶面边界边”表达封闭链，并生成单个圆角集合。

同时建议把当前能力边界写入工具 schema 的 `description` 或错误提示，避免用户误以为多个 `{"edge": ...}` 会自动合并成一条 Creo 边链。

---

## 6. 结论

v0.26.0 的保存与回滚稳定，几何选择器也能正确定位 P03 顶面 8 条边；真正阻断重建的是 `round` 缺少 edge-chain / multi-edge-per-set 支持。该问题已由源码、能力表、工具说明和三次实机作业共同验证。
